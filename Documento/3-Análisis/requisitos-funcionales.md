# Requisitos funcionales

*Proyecto: Registro del estado energético del aula 504 comparado con la programación académica · Ingeniería de Software I · Corporación Universitaria Remington · Hilary Pérez Zúñiga y Luijeimm Agudelo Godoy.*

## Cuadrante 3 · 5. Requisitos funcionales

Los requisitos funcionales siguen la forma de la norma ISO/IEC/IEEE 29148 (ISO, 2018b): condición, el sistema, acción, objeto y restricción. Cada uno nace de al menos un criterio de aceptación. Tres requisitos son verificados por dos criterios (la superposición se prueba con un caso rechazado y uno contiguo aceptado; cada deshacer se prueba con una recuperación y con el orden de la pila), y dos criterios de persistencia verifican cada uno dos requisitos (guardar y cargar). RF-79 y RF-80 se agregaron en la versión 3.1 para que la pila de deshacer no se desborde; se numeraron al final para no cambiar los códigos anteriores.
