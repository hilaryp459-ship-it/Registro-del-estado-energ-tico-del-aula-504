# Registro del estado energético del aula 504

Sistema digital para registrar manualmente el estado energético del aula 504 y compararlo con la programación académica, identificando posibles inconsistencias en el uso de computadores, luminarias y aire acondicionado.

Proyecto de Ingeniería de Software I, Corporación Universitaria Remington. Integrantes: Hilary Pérez Zúñiga (PROGRAMACION_ACADEMICA) y Luijeimm Agudelo Godoy (REGISTRO_ESTADO y consultas).

> El sistema no mide el consumo eléctrico ni confirma que exista desperdicio de energía: solo documenta situaciones que podrían indicar un uso innecesario de los equipos.

## Contenido

| Carpeta | Qué tiene |
|---|---|
| `Documento/1-Contexto` | Actores, entrevista (formulario) y observaciones |
| `Documento/2-Objetivos` | Objetivo general y objetivos específicos |
| `Documento/3-Análisis` | Historias de usuario con criterios de aceptación y requisitos funcionales |
| `Prototipo` | Código Java del prototipo (8 clases) y sus instrucciones |

## Ejecutar el prototipo

```bash
cd Prototipo
javac *.java
java Main
```
